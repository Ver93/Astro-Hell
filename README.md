
# Astro Hell

A modern web application built with React and Vite.

## Overview

This project is developed using React and Vite, providing a fast and modern development environment with Hot Module Replacement (HMR).

The application is designed with a component-based architecture, making it easy to maintain, extend, and customize.

## Tech Stack

- **React** – Component-based UI development
- **Vite** – Fast frontend build tool and development server
- **JavaScript** – Application logic
- **CSS** – Styling and layout

## Getting Started

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)

### Installation

Clone the repository:

```bash
git clone https://github.com/ver93/astro-hell-web.git
```

Navigate into the project directory:

```bash
cd REPOSITORY
```

Install dependencies:

```bash
npm install
```

### Development

Start the local development server:

```bash
npm run dev
```

Vite will provide a local URL, usually:

```text
http://localhost:5173
```

### Production Build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

*The structure may vary depending on the project.*

## Development Tools

- Vite Hot Module Replacement (HMR)
- ESLint / Oxlint for code quality (depending on configuration)
